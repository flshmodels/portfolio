Flash Remote Check

This is a Python tool for reviewing Roblox server code. Give it a folder of scripts and it finds incoming remote handlers, then points out places to check for input validation, request limits or client data being passed on.

It reads the source without running it. A lexer separates code from comments and strings, and the analyzer looks through the callbacks it supports. Each result includes a file, line and column so you can go straight to the code. Reports can be plain text, JSON or SARIF.

The tests cover things like nested handlers, escaped strings, broken input and report output. It still needs a person to read the results: it doesn’t follow values across files or prove that a validation function works. Syntax it can’t handle is reported as an incomplete scan.

Flash Canvas

Canvas lets you try out a Roblox-style UI in your browser. You edit a JSON layout, render it at different sizes, and export a Luau function that creates the frames, text and buttons in Studio.

The layout keeps Roblox’s scale, offset and anchor values, so it isn’t tied to one screen size. The browser and command-line exporter share the same validation and code generation. If you edit the layout, you have to render it successfully before exporting again.

It runs locally and doesn’t send your files anywhere. The preview uses browser elements rather than Roblox’s renderer, so text and clipping can look different in Studio. The export builds the UI; you add the button handlers and game logic.

Flash Inspect

Inspect is a Studio plugin that checks tagged scenery and interaction IDs. It finds unanchored scenery, objects with missing or invalid IDs, and objects sharing the same ID. Clicking a result selects it in Studio.

You can scan all of Workspace or just your selection. A scenery tag on a model also applies to the parts inside it, and selecting both a model and one of its children won’t scan the same object twice.

It doesn’t change anything in the place. An unanchored part might be intentional, so you decide what needs fixing. Duplicate IDs are only checked within the area you scan. The checks have automated tests, but the plugin panel still needs a live Studio test.
